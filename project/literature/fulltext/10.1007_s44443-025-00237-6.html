Abstract

Code completion and code repair have become fundamental tasks in software engineering and machine learning research. However, existing large language models (LLMs) for code generation, predominantly based on autoregressive modeling (ARM), exhibit limitations when dealing with incomplete or buggy code snippets, especially when the missing or erroneous spans are located arbitrarily within the sequence. In this paper, we propose CodeDiffuSe, a novel masked diffusion framework specifically designed for structure-aware code completion and repair. Unlike traditional ARM approaches, CodeDiffuSe learns to recover missing code spans by leveraging both left and right context, enabling bidirectional reasoning and flexible infilling. We introduce a syntax-aware masking strategy that randomly masks entire Abstract Syntax Tree (AST) subtrees during training, and a semantic consistency regularization that encourages type-correct and syntactically valid predictions. During inference, we propose an error-aware remasking mechanism that dynamically identifies uncertain or invalid tokens and selectively refines them across adaptive reverse diffusion steps. Extensive experiments on standard code completion and bug repair benchmarks, including CodeXGLUE, Defects4J, and QuixBugs, demonstrate that CodeDiffuSe consistently outperforms strong autoregressive baselines such as CodeGen, CodeEditorBench, and InCoder across multiple programming languages. Our work introduces a structure- and semantics-aware diffusion-based alternative for code completion and repair, offering consistent gains in both syntactic validity and functional correctness across diverse benchmarks. Rather than claiming to replace existing paradigms, we demonstrate how diffusion models can complement and improve upon autoregressive and retrieval-based approaches in structure-sensitive settings.

1 Introduction

Software development increasingly relies on automated code generation and editing tools to enhance programmer productivity, reduce development costs, and ensure software reliability. Recent advancements in large language models (LLMs) have enabled significant progress in code-related tasks, including code completion, synthesis, and bug repair Chen et al. (2021); Nijkamp et al. (2023); Fried et al. (2022); Wang et al. (2023b). These models, such as Codex Chen et al. (2021) and CodeGen Nijkamp et al. (2023), have demonstrated the ability to generate complex code snippets from natural language prompts or partial code fragments. However, the dominant paradigm underlying most existing code LLMs is autoregressive modeling (ARM), wherein code is generated sequentially, token-by-token, conditioned on previously generated tokens.

Despite their success, autoregressive models exhibit fundamental limitations when applied to structured code tasks such as code completion in the middle of a sequence, bug repair, or infilling missing AST subtrees. Sequential left-to-right generation constrains the model to rely only on the preceding context at each generation step, often leading to incoherence when future context is crucial. Moreover, in code completion and repair scenarios, missing or buggy spans may appear arbitrarily within the code, not necessarily at the end, making it difficult for purely sequential models to reason effectively Fried et al. (2022); LeClair et al. (2020). These shortcomings manifest as error propagation, inability to properly capture bidirectional dependencies, and challenges in preserving syntactic correctness, particularly when repairing complex or long-range code dependencies Roziere et al. (2021).

Recently, masked generative modeling approaches, particularly diffusion models, have emerged as promising alternatives to sequential generation in natural language processing and vision domains Austin et al. (2021); Li et al. (2022); Han et al. (2024). Instead of predicting the next token, diffusion-based models gradually corrupt input sequences and learn to denoise them, allowing simultaneous modeling of the entire output structure. Early explorations such as Diffusion-LM Li et al. (2022) and have demonstrated that masked diffusion can match or even outperform autoregressive models for text generation. However, the potential of masked diffusion frameworks for highly structured outputs such as source code — which requires strict syntactic and semantic correctness — remains largely unexplored.

In this work, we propose CodeDiffuSe, a novel masked diffusion framework specifically designed for structure-aware code completion and repair tasks. Unlike prior masked diffusion models focused on natural language, CodeDiffuSe leverages the syntactic structure of source code by performing syntaxaware masking over Abstract Syntax Trees (ASTs). This enables the model to mask and recover entire meaningful AST subtrees, such as functions, loops, and conditional blocks, rather than masking arbitrary tokens. Furthermore, we introduce semantic consistency regularization, which encourages generated completions to adhere to programming language syntax rules and type constraints. During inference, we propose an error-aware remasking strategy that adaptively identifies and refines lowconfidence or syntactically invalid predictions through iterative reverse diffusion steps. By combining syntax-aware pretraining, semantic regularization, and adaptive sampling, CodeDiffuSe provides a principled alternative to sequential generation for structured code modeling.

We conduct comprehensive experiments on standard code completion and bug repair benchmarks,including CodeXGLUE Lu et al. (2021), Defects4J Just et al. (2014), QuixBugs Lin et al. (2017), and compare CodeDiffuSe against state-of-the-art autoregressive models such as CodeGen Nijkamp et al. (2023), CodeEditorBench Guo et al. (2024), and InCoder Fried et al. (2022). Experimental results demonstrate that CodeDiffuSe consistently achieves superior performance across multiple programming languages in terms of exact match accuracy, semantic preservation, and compilation success rates. Ablation studies further validate the importance of syntax-aware masking, semantic regularization, and error-aware remasking in enhancing model robustness and generation quality.

While autoregressive and retrieval-augmented methods have dominated code generation, our findings suggest that masked diffusion models provide a viable and robust alternative—particularly for tasks involving infilling, bug repair, and structural recovery. CodeDiffuSe illustrates how integrating AST-based structure with denoising generation opens a promising direction for future work in structured code modeling.

Our core contribution lies in integrating masked diffusion with structure- and semantics-aware constraints, enabling more robust and interpretable code infilling and repair. This combination is theoretically motivated and empirically validated through extensive evaluation and ablation studies. Our contributions are as follows:

  • We propose CodeDiffuSe, a masked diffusion framework tailored to structure-aware code generation.

  • The model utilizes abstract syntax trees and semantic regularization to enhance prediction fidelity. • We provide comprehensive empirical evaluations across standard code repair and completion datasets.

2 Related work

Code completion and repair have been historically approached through autoregressive decoding, often using large-scale transformer architectures. Early work such as DeepCoder Balog et al. (2016) and Bayou Allamanis et al. (2017) laid the foundation for neural program synthesis from partial input-output specifications. With the rise of pre-trained large language models (LLMs), OpenAI’s Codex Chen et al. (2021) demonstrated strong performance in code generation from natural language prompts, showcasing the utility of massive code corpora in supervised pretraining.

CodeGen Nijkamp et al. (2023) and CodeEditorBench Guo et al. (2024) extended these capabilities to code completion and editing. InCoder Fried et al. (2022) introduced infilling with a non-causal attention mechanism, conditioning on both past and future context. CodeT5 Wang et al. (2021) and its improved version CodeT5+ Wang et al. (2023b) provided a unified Seq2Seq framework that supports both code understanding and generation. CodeRL Le et al. (2022) integrated reinforcement learning with code generation to optimize functional correctness.

Despite their effectiveness, these models rely heavily on left-to-right decoding or causal masking, which introduces limitations when reasoning over bidirectional context or incomplete code segments. Moreover, while retrieval-augmented methods such as ReCode Wang et al. (2023a) and PLBART Ahmad et al. (2021) bring additional information from similar examples, they often fail to generalize well in scenarios where retrieved candidates lack structural alignment with the input.

Infilling, where models generate missing spans conditioned on both left and right contexts, better mimics real-world software maintenance scenarios. InCoder Fried et al. (2022) and FIM Raychev et al. (2014) introduced infilling objectives within autoregressive training by modifying positional encodings. However, these methods still fundamentally rely on sequence-level token modeling without enforcing structure.

Defects4J Just et al. (2014) and QuixBugs Lin et al. (2017) provide benchmarks for program repair, leading to neural repair systems like Long and Rinard (2016), DeepFix Gupta et al. (2017). These models leverage code transformations, templates, or fine-tuned LLMs for generating patches. Nonetheless, most lack explicit modeling of structural constraints or semantic correctness during generation, making them prone to syntactic errors or functionally invalid code.

MLM-based pretraining for code, inspired by BERT Devlin et al. (2019), has been extensively adopted for representation learning. CodeBERT Feng et al. (2020), and GraphCodeBERT Guo et al. (2020) apply masked token prediction to learn code embeddings that capture syntactic and semantic relationships. These embeddings have proven useful in downstream tasks such as classification, code search, and clone detection.

C-BERT Karampatsis and Sutton (2020) and CoTexT Phan et al. (2021) extend MLMs with code-specific masking strategies, such as identifier or block-level masking, and multi-task learning. However, MLMs are limited by their non-generative nature and inability to directly reconstruct full sequences, particularly under structured masking or infilling settings. Thus, while useful for encoding, they fall short as generative models for structure-aware completion or repair.

Diffusion models have become state-of-the-art in continuous domains such as image generation Dhariwal and Nichol (2021). Extensions to discrete domains include Structured Denoising Diffusion Models (SDDMs) Austin et al. (2021), Diffusion-LM Li et al. (2022). These models apply iterative noise addition and denoising to generate discrete sequences and have achieved promising results in natural language generation.

MaskGIT Chang et al. (2022) proposed parallel denoising with masking schedules for efficient generation. In the context of code, CodeFusion Singh et al. (2023) is a pioneering attempt to apply masked diffusion to code token infilling. While effective in token reconstruction, CodeFusion lacks structural priors such as AST awareness and semantic constraints, and it is limited to short sequences.

Diffusion modeling for code remains in early stages, and its potential to model program structure and semantics is not yet fully realized. Our work builds on these foundations and introduces ASTguided diffusion with semantic regularization.

Structured representations of code, such as Abstract Syntax Trees (ASTs), are central to program analysis. Tree2Tree Chen et al. (2018), and grammar-based decoding Rabinovich et al. (2017) encode ASTs for sequence prediction. Graph-based models such as GGNNs Allamanis et al. (2017), ASTNN Zhang et al. (2019), and GraphCodeBERT Guo et al. (2020) incorporate data and control flow into neural encoders.

However, most of these methods either rely on fully observed code or focus on classification. Their generative components operate autoregressively and do not utilize structural corruption or masked diffusion. Ensuring semantic correctness, including type consistency and compilability, has been addressed by Hellendoorn et al. (2019) and Getafix Bader et al. (2019), yet such properties are rarely embedded into end-to-end generative models. Despite advancements, key limitations remain:

  • Bidirectional Context Modeling: Most models generate code left-to-right and cannot fully utilize future context.

  • Lack of Structural Priors: Structural information like ASTs is often not integrated into the generation procedure.

  • No Semantic Enforcement: Models rarely guarantee syntactic validity or type safety during generation.

  • Limited Diffusion Adoption: Diffusion remains underutilized in code generation compared to NLP or vision.

To address these, we propose CodeDiffuSe, a masked diffusion model that:

  • Performs AST-aware masking to preserve structural boundaries;

  • Applies semantic regularization to guide generation toward compilable code;

  • Introduces adaptive remasking for iterative refinement;

  • Achieves strong performance across multiple languages and repair benchmarks.

Table 1 summarizes key characteristics of recent code generation models. As shown, CodeDiffuSe is the only framework that jointly incorporates AST-based structural reasoning, semantic constraint enforcement, masked diffusion, and bidirectional generation.

Despite the growing literature on code generation and diffusion models, our work is the first to jointly integrate syntactic structure and semantic constraints within a masked denoising diffusion framework for code. Unlike prior autoregressive models (e.g., CodeGen, CodeT5 +) or non-structural diffusion approaches (e.g., CodeFusion), CodeDiffuSe uniquely offers:

  • AST-guided masking: enables structure-aware corruption and recovery at the syntactic subtree level.

  • Semantic consistency regularization: ensures type safety and syntactic validity via compiler feedback, which is absent in all prior diffusion-based models.

  • Entropy-based remasking: adaptively focuses denoising on uncertain or structurally invalid regions.

  • Adaptive step control: reduces inference cost without compromising correctness, a mechanism not explored in prior work.

These innovations position CodeDiffuSe as a fundamentally different approach from prior sequence-level or token-noise-based generative models, bridging the gap between symbolic structure and data-driven generation.

3 Methodology

In this section, we introduce CodeDiffuSe, a novel masked denoising diffusion framework designed specifically for structure-aware code completion and repair. The core idea is to model the conditional distribution of a clean source code sequence given a partially corrupted version, leveraging a diffusionbased generative process that progressively denoises masked or buggy code spans.

Unlike autoregressive generation, the masked diffusion formulation allows bidirectional conditioning over missing code spans, which is crucial for realistic code editing tasks where context appears on both sides of a gap. Furthermore, the use of AST-guided corruption introduces a structured inductive bias, enabling the model to reason over semantically meaningful code fragments (e.g., blocks, functions) rather than flat token sequences. This contrasts with traditional token-noise models and enhances generalization to unseen code structures.

The framework consists of the following key components:

  • A syntax-aware masking mechanism that leverages Abstract Syntax Tree (AST) structures to mask meaningful code fragments during training;

  • A forward corruption process that creates masked sequences through progressive subtree-level masking;

  • A reverse denoising process that reconstructs missing tokens using a bidirectional Transformerbased decoder;

  • A semantic consistency regularization module that enforces syntactic validity and type correctness;

  • An error-aware remasking strategy to iteratively refine uncertain or invalid predictions during inference;

  • An adaptive step control mechanism to determine when to halt the diffusion process based on reconstruction confidence.

The structure-aware inference loop illustrated in Figure 1 reveals several key advantages of the proposed framework. First, the explicit use of AST-guided masking and type checking allows the model to iteratively refine uncertain regions while maintaining structural and semantic validity at each step. This enables CodeDiffuSe to recover from noisy or incomplete inputs more robustly than classical autoregressive decoders, which lack external syntax feedback. Second, the entropy- and typebased gating logic provides a principled stopping criterion that balances accuracy and efficiency, preventing unnecessary remasking. Nevertheless, this design also introduces a computational overhead due to repeated parsing and constraint checking, especially in deeply nested code. While this is mitigated by early stopping and masking thresholds, future work may investigate lightweight syntactic approximations or learned surrogates to improve runtime efficiency without compromising structural awareness.

We begin by defining the problem formulation and notations, and then elaborate each component of the CodeDiffuSe framework in the subsequent subsections.

3.1 Problem formulation

Let V denote the vocabulary of code tokens, and let x0 = (x1,x2,...,xL) represent a clean source code sequence of length L, where each token xi ∈ V. The primary objective of CodeDiffuSe is to learn a generative model that, given a partially masked or corrupted version xt of x0, can accurately reconstruct the original sequence.

To achieve this, we define a forward corruption process q(xt | x0) that selectively masks a subset of tokens or structured spans (e.g., AST subtrees) in the original sequence x0, resulting in a corrupted sequence xt.

The reconstruction task is handled by a reverse denoising model pθ(x0 | xt), parameterized by θ, which is trained to predict the masked tokens using the visible (non-masked) context. Importantly, this formulation allows the model to exploit both preceding and succeeding tokens, unlike autoregressive methods that rely solely on left-to-right generation.

The overall training objective is to minimize the expected reconstruction loss across the training data distribution D:

$$\mathcal{L}\left(\uptheta \right)={E}_{{x}_{0}\sim {\mathbb{D}},{}_{t}\sim q\left({x}_{0}|{x}_{0}\right)}\left[\text{l}\left({x}_{0},{p}_{\uptheta }\left({x}_{0}|{x}_{t}\right)\right)\right]$$
(1)

where ℓ(·,·) denotes a token-level loss function, instantiated as a masked cross-entropy loss computed only over the corrupted positions.

Unlike prior diffusion models designed for natural language, CodeDiffuSe introduces a treestructured corruption process by masking over Abstract Syntax Tree (AST) subtrees. This enables syntactic block-level reasoning, providing a new theoretical lens on structured denoising in code generation, which fundamentally differs from flat sequence modeling.

Unlike autoregressive generation models that operate in a unidirectional fashion, the conditional distribution pθ(x0 | xt) in CodeDiffuSe is inherently bidirectional, conditioning on both left and right context. This property is crucial for handling infilling and repair tasks where missing or buggy code spans appear arbitrarily within the sequence.

3.2 Syntax-aware masking strategy

Standard token-level masking strategies, such as those employed in BERT-style models Devlin et al. (2019), are often inadequate for source code, where syntactic coherence and structural dependencies are paramount. Token-wise masking may inadvertently disrupt critical constructs such as control-flow blocks or function bodies, making reconstruction both ambiguous and semantically inconsistent.

To address this limitation, we propose a syntax-aware masking strategy that operates over the Abstract Syntax Tree (AST) representation of source code. This strategy enables masking at the level of well-defined syntactic units, thereby preserving structural granularity and encouraging the model to learn coherent code generation patterns.

Given an input code sequence x0, we parse it into its corresponding AST. Let S = {s1,s2,…,sK} denote the set of all identifiable syntactic AST subtrees extracted from the AST—these may include function definitions, loop constructs, conditional statements, or other hierarchical code segments.

At each diffusion step t, we sample a subset of these AST subtrees, denoted by St ⊆ S, according to a predefined masking ratio αt ∈ (0,1). All tokens belonging to the selected AST subtrees are then masked in the corrupted sequence xt.

Formally, the syntax-aware masking function SyntaxMask(x0,αt) is defined as:

$${x}_{t}^{i}=M,iftoken{x}_{i}belongstoasubtrees\in {\mathcal{S}}_{\mathcal{t}},$$

Masking entire syntactic units—rather than isolated tokens—encourages the model to reason over higher-level code constructs, enabling the recovery of semantically coherent and structurally valid fragments. This strategy aligns closely with the hierarchical nature of source code and improves generalization across functionally similar patterns.

In practice, we use the Tree-sitter library to parse input source code into ASTs. Each programming language (e.g., Python, Java, JavaScript) is parsed using its language-specific grammar. For each AST, identifiable AST subtrees such as FunctionDeclaration, IfStatement, and ForLoop nodes are selected as maskable units. This ensures consistent syntactic granularity across languages.

3.3 Forward diffusion process

The forward process q(xt | x0) defines a stochastic corruption trajectory that incrementally transforms the original, uncorrupted code sequence x0 into a fully masked version xT over T discrete diffusion steps. This process simulates a progressive degradation of structured information and serves as the foundation for training the reverse denoising model.

At each timestep t ∈ {1,2,...,T}, a masking ratio αt ∈ (0,1) is sampled, and the syntax-aware masking function (defined in Equ. 2) is applied to produce the corrupted sequence xt from x0:

$$q\left({x}_{t}|{x}_{0}\right)={\text{SyntaxMask}}\left({x}_{0},{\alpha }_{t}\right)$$
(3)

where αt is typically drawn from a uniform distribution, i.e., αt ∼ U(0,1), unless a task-specific masking schedule (e.g., linear or cosine decay) is employed to control the masking intensity over time. To model the forward corruption process q(xt | x0), we adopt a masking strategy that progressively occludes code tokens based on their structural role in the abstract syntax tree (AST). While the functional form of the corruption appears deterministic, the actual masking process incorporates stochasticity through randomized sampling of corruption spans. In particular, given a randomly selected AST node as the masking center, the surrounding nodes are masked according to an exponential decay distribution over the syntactic distance. This mechanism injects structured noise into the input space while preserving language-level coherence, serving as a discrete analogue to Gaussian noise in classical diffusion models.

This forward corruption process yields a sequence of progressively noisier representations:

$${x}_{0} \to {x}_{1} \to {x}_{2} \to \cdot \cdot \cdot \to xT,$$

where the final state xT may correspond to a nearly or fully masked code sequence.

The forward diffusion process can be viewed as a structured masking pipeline that removes increasingly larger or deeper syntactic components from the input sequence. Unlike token-level noise injection in standard masked language modeling, this approach preserves hierarchical coherence during corruption. The reverse model must then learn to denoise and reconstruct syntactically meaningful spans, making the task both more realistic and semantically grounded.

3.4 Reverse diffusion and mask prediction

The reverse diffusion process aims to reconstruct the original code sequence x0 from its partially corrupted version xt through a sequence of iterative denoising steps. This process is parameterized by a Transformer-based masked language model pθ, which is trained to predict the masked tokens conditioned on the visible (non-masked) context at each timestep.

Given the corrupted sequence xt, the model estimates a conditional distribution over the vocabulary for each token position:

$${p}_{\uptheta }\left({x}_{i}|{x}_{t}\right),\hspace{1em}\forall i\in \{\text{1,2},\dots ,L\}$$
(4)

However, to avoid overfitting to already visible tokens and to focus learning on reconstruction, the training objective is restricted to the masked positions. Let Mt ⊆ {1,…,L} denote the set of indices corresponding to masked tokens at timestep t. The masked cross-entropy loss is then defined as:

$${\mathcal{L}}_{\text{mse-C}}=-\frac{1}{\left|{\mathcal{M}}_{\mathcal{t}}\right|}{\sum }_{i\in {\mathcal{M}}_{\mathcal{t}}}\text{log}{p}_{\theta }\left({x}_{i}|{x}_{t}\right)$$
(5)

where xi denotes the ground-truth token at position i in the original sequence x0.

Unlike autoregressive models that rely solely on left-to-right token prediction, the masked denoising formulation of CodeDiffuSe allows each token to be predicted using both its left and right context. This bidirectional conditioning is especially advantageous in code infilling and repair scenarios, where missing or erroneous tokens often appear in the middle of the sequence and require reasoning about their surrounding structural and semantic context.

3.5 Semantic consistency regularization

While accurate token reconstruction is essential, it alone does not guarantee the correctness or usability of generated code. In real-world applications, syntactic validity and semantic consistency—such as adherence to type constraints—are critical for code compilation and execution. To address this, we augment the core training objective with a semantic consistency regularization mechanism, which introduces two auxiliary loss components to promote functional correctness:

  • Syntactic Validity Loss: Penalizes outputs that cannot be parsed into a valid Abstract Syntax Tree (AST), thereby encouraging syntactically well-formed code.

  • Type Consistency Loss: Penalizes type errors identified via static type checking, promoting type-safe outputs.

Let ASTCheck(x) be a binary-valued function that returns 1 if the generated sequence x is syntactically valid (i.e., parsable into a valid AST), and 0 otherwise. $${\mathcal{L}}_{\text{tp}}={E}_{{x}_{t}}\left[1-{\text{TypeCheck}}\left(\widehat{{x}_{0}}\right)\right]$$

These losses are linearly combined to form the total semantic regularization term:

$${\mathcal{L}}_{\text{smni}}={\uplambda }_{\text{syntax}}\cdot {\mathcal{L}}_{\text{sna}}+{\uplambda }_{\text{type}}\cdot {\mathcal{L}}_{\text{tp}}$$

where λsyntax and λtype are non-negative hyperparameters that control the contribution of each regularizer to the overall training objective.

During training, semantic and syntactic losses are incorporated jointly with the token reconstruction loss. We empirically determine the regularization weights (λsyntax,λtype) via a grid search over the range {0.1, 0.5, 1.0} using the CodeXGLUE validation set. At inference time, syntactic and type validity are used as binary criteria for adaptive remasking and early stopping. This dual use ensures consistent constraint enforcement throughout the pipeline.

By explicitly incorporating both syntactic and semantic correctness into the training process, CodeDiffuSe moves beyond token-level generation and aligns the model’s output space with the fundamental constraints of programming languages. This results in code that is not only more accurate but also more likely to compile and execute correctly in practical settings.

3.7 Adaptive diffusion step control

Conventional diffusion models typically operate with a fixed number of reverse denoising steps T, applied uniformly to all samples. However, in the context of code generation, this uniform scheduling is often inefficient—some examples converge rapidly to a valid output, while others require additional refinement. To address this imbalance, we introduce a dynamic step control mechanism that adaptively determines when to terminate the reverse diffusion process based on the current quality of the reconstruction.

Our stopping criterion combines two complementary signals:

  • Mask Ratio: If the proportion of remaining masked tokens at step t falls below a predefined threshold ϵ, i.e., the reconstruction is nearly complete.

  • Syntactic and Type Validity: If the partially reconstructed sequence xt passes both syntactic parsing and static type checking.

Formally, the diffusion process is terminated at timestep t when the following condition is satisfied:

$$\text{Stop at }t\hspace{1em}{\text{if}}\hspace{1em}\frac{\left|{\mathcal{M}}_{\mathcal{t}}\right|}{L}<\upepsilon \hspace{1em}{\text{and}}\hspace{1em}{\text{ASTCheck}}\left({x}_{t}\right)=1\hspace{1em}{\text{and}}\hspace{1em}{\text{TypeCheck}}\left({x}_{t}\right)=1$$
(11)

where Mt is the set of masked token indices at time t, L is the total number of tokens in the sequence, and ϵ is a tunable threshold that governs early stopping sensitivity.

This adaptive stopping criterion enables the model to reduce inference time by avoiding unnecessary denoising steps for well-formed or trivially corrupted inputs. At the same time, it ensures that structurally complex or severely corrupted code sequences continue to receive sufficient refinement until they become syntactically and semantically valid. This dynamic mechanism thus balances computational efficiency and reconstruction quality in a principled manner.

The overall training objective of CodeDiffuSe integrates two key components: (i) a masked crossentropy loss that focuses on accurate token reconstruction, and (ii) a semantic regularization term that enforces syntactic and type-level correctness. The combined loss function is defined as:

$${\mathcal{L}}_{total}={\mathcal{L}}_{\text{maksed-C}}+{\mathcal{L}}_{\text{semantic}}$$

where Lmasked-CE is the token reconstruction loss defined in Equ. (6), and Lsemantic is the semantic regularization term defined in Equ. (9).

This composite objective ensures that the model is simultaneously optimized to:

  • Accurately reconstruct masked tokens using full bidirectional context;

  • Generate syntactically valid and type-consistent code sequences;

  • Leverage structural priors and runtime diagnostics for robust generation; • Dynamically adapt inference behavior through remasking and early stopping.

Language-Specific AST and Type Checking

We adopt Tree-sitter for AST extraction, which supports multiple languages with official grammar definitions. For static type analysis, we integrate mypy for Python and javac for Java. In JavaScript, where static typing is weaker, we utilize ESLint and manually defined type stubs to catch basic type inconsistencies. AST and type check failures are logged during preprocessing, and corrupted samples are either corrected via parser fallback or excluded if unrecoverable.

By tightly integrating syntax-aware masking, semantic regularization, error-aware remasking, and adaptive diffusion step control, CodeDiffuSe offers a principled and robust alternative to autoregressive modeling for code completion and repair. The framework unifies structure- and semantics-aware learning under the masked diffusion paradigm, paving the way for reliable and context-sensitive code generation.

3.9 Methodological summary and implementation considerations

CodeDiffuSe introduces a novel masked diffusion framework tailored for structure-aware code completion and repair. It departs from conventional autoregressive paradigms by enabling bidirectional reasoning through masked denoising over Abstract Syntax Tree (AST) subtrees. The methodology integrates syntax-aware masking, semantic consistency regularization, error-aware remasking, and adaptive inference termination. Together, these components offer a unified framework capable of reconstructing corrupted code spans in a syntax- and type-consistent manner.

From a theoretical perspective, our model differs from prior text-oriented diffusion approaches by encoding inductive structural biases through AST-aware masking and enforcing functional constraints via semantic regularization. This positions CodeDiffuSe as the first structured denoising diffusion model for program synthesis that explicitly integrates symbolic structure and static correctness checks into its generative dynamics.

To support reproducibility and practical deployment, we summarize key implementation configurations:

  • AST Parsing: Source code is parsed into ASTs using Tree-sitter, which supports major languages including Python, Java, and JavaScript.

  • Model Architecture: The reverse denoising model pθ is implemented as a 12-layer Transformer encoder with 768 hidden units, 12 attention heads, and GELU activations. Inputs are subwordtokenized using byte-pair encoding (BPE).

  • Training Configuration: Models are trained using the AdamW optimizer with β1 = 0.9, β2 = 0.98, and weight decay of 10−4. A cosine Learning rate scheduler is used with an initial Learning rate of 5× 10−5 and batch size 32.

  • Masking Schedule: The masking ratio αt increases Linearly from 0.15 to 0.90 across T = 10 diffusion steps. Masked tokens are denoted by a special token < MASK >.

  • Syntactic and Type Validation: We implement ASTCheck and TypeCheck using ast for Python, javac for Java, and mypy for static type analysis.

  • Thresholds: The remasking entropy threshold is set to τ = 1.5, and the adaptive stopping criterion uses ϵ = 0.05 as the minimum mask ratio.

The integration of adaptive stopping Leads to a reduction of up to 32% in average inference steps compared to fixed-step settings. While remasking introduces minor computational overhead, it significantly improves denoising accuracy and convergence stability. All experiments are conducted on NVIDIA A100 GPUs using mixed-precision training.

Despite its effectiveness, CodeDiffuSe has several limitations:

  • Language Dependence: The reliance on AST parsing requires language-specific parsers and limits generalization to poorly supported or loosely typed languages.

  • Training Cost: Diffusion-based denoising requires multiple denoising iterations, resulting in longer training and inference times relative to autoregressive models.

  • Static Checking Coverage: Type checking effectiveness varies across languages; dynamically typed code may evade detection of subtle semantic inconsistencies.

4.2 Baselines

We compare CodeDiffuSe against a diverse set of strong baselines, encompassing both autoregressive and non-autoregressive generation paradigms:

  • CodeGen Nijkamp et al. (2023): A decoder-only Transformer trained on the Pile and BigCode datasets for large-scale autoregressive code generation.

  • CodeEditorBench Guo et al. (2024): A causal Transformer model with support for Fill-in-theMiddle (FIM) generation, trained on permissively licensed GitHub repositories.

  • CodeT5 + Wang et al. (2023b): A unified encoder-decoder model pretrained for multiple code understanding and generation tasks, fine-tuned for both completion and repair.

We additionally include PLBART? and ReCode? as strong non-autoregressive baselines. PLBART provides multitask capabilities for repair and completion, while ReCode combines retrieval with generation for adaptive bug fixing.

All baselines are evaluated using their open-source checkpoints or reproduced with equivalent training protocols.

4.4 Training and inference setup

All experiments are conducted on NVIDIA A100 GPUs with 40GB memory using PyTorch 2.0 and HuggingFace Transformers.

  • Model Architecture: CodeDiffuSe uses a 12-layer Transformer encoder with 768 hidden dimensions and 12 attention heads. Token embeddings are shared across input and output layers.

  • Optimization: Models are trained with AdamW optimizer (β1 = 0.9, β2 = 0.98) and Linear warm-up for 2,000 steps. Peak Learning rate is set to 5× 10−5.

  • Masking Schedule: The forward process uses 10 diffusion steps with Linearly increasing mask ratios from 15 to 90%.

  • Inference Thresholds: The remasking entropy threshold is τ = 1.5, and early stopping mask ratio threshold is ϵ = 0.05.

  • Batch Size and Training Time: Models are trained with a batch size of 32 for 100 K steps. End-to-end training takes approximately 3.5 days per dataset.

To ensure fairness, all models are evaluated under identical preprocessing, tokenization, and evaluation protocols. Results are averaged over three independent runs with different random seeds.

5.15 Limitations and generalizability

Language Dependence

The model currently relies on language-specific abstract syntax trees (ASTs) and type inference tools. As such, adaptation to new programming languages requires access to reliable parsers and semantic analyzers. Dynamically typed languages (e.g., Python, JavaScript) present further challenges due to the absence of explicit type annotations, potentially limiting the effectiveness of our semantic consistency mechanisms.

Functional and Low-Level Paradigms

Our current design primarily targets imperative, statically typed languages (e.g., Java, C#). Functional programming languages (e.g., Haskell, OCaml) and low-level codebases (e.g., C, embedded code) may require redefinition of structural priors, such as control-flow sensitivity or higher-order AST representations.

Training Cost and Diffusion Overhead

Despite recent optimizations, masked diffusion remains computationally expensive compared to autoregressive decoding. While our model achieves better sampling efficiency than earlier discrete diffusion methods, training still requires multiple denoising iterations and AST-guided masking, which may be resource-intensive for industrial-scale deployment.

Generalizability

We have evaluated CodeDiffuSe on datasets spanning three programming languages, but further work is needed to test its adaptability to mixed-language codebases, nonEnglish identifiers or comments, and cross-language code migration scenarios. Future research could explore incorporating multilingual pretrained embeddings and universal AST representations.

While CodeDiffuSe introduces promising capabilities, broader adoption will depend on addressing these language-specific, architectural, and computational challenges.

These improvements validate our core hypothesis (RQ1) that syntax- and semantics-aware masked diffusion can lead to more robust and functionally reliable code generation.

The ablation studies (Section 5.3) offer further insight into the architectural contributions. Syntaxaware masking, which aligns the corruption process with the structural boundaries of code, yields the most substantial gains in syntactic coherence and compilation success. Semantic regularization based on AST and type checking enhances the model’s ability to produce type-safe and parsable outputs, while remasking and adaptive step control improve denoising stability and computational efficiency. These findings affirm the effectiveness of each component in contributing to overall model performance (RQ2), and clarify how the integration of symbolic constraints into the generative process provides concrete advantages.

With regard to efficiency (RQ3), our convergence analysis (Section 5.4) reveals that CodeDiffuSe achieves comparable or superior accuracy with significantly fewer reverse diffusion steps compared to fixed-step alternatives, thus enabling faster inference without compromising quality. This is particularly relevant for real-world applications where latency is a practical constraint.

The qualitative analysis (Section 5.5) highlights the model’s strengths in preserving block-level syntactic structures and ensuring semantic alignment across infilled spans. CodeDiffuSe demonstrates resilience in scenarios involving complex edits, nested structures, and variable renaming, confirming its robustness under semantically neutral perturbations (RQ4, RQ5). Furthermore, the model generalizes effectively across different programming paradigms—object-oriented, procedural, and functional—as shown in our cross-paradigm evaluation (Section 5.7), addressing RQ6.

Despite these promising results, several limitations must be acknowledged. First, the framework relies on language-specific AST parsers and type checkers, which limits its direct applicability to languages with limited tooling support or dynamic typing characteristics. Second, although the diffusion paradigm offers improved controllability and interpretability, it incurs greater computational cost during training and inference due to iterative denoising. Third, while our semantic consistency module enforces basic syntactic and type-level correctness, it does not yet capture deeper program semantics such as logical invariants or execution traces. Finally, the current evaluation is limited to three programming languages; extending the framework to multilingual and cross-language scenarios remains a valuable direction for future research.

In summary, the proposed CodeDiffuSe framework offers a principled integration of structure and semantics into the diffusion-based code generation paradigm. While certain technical constraints remain, our extensive empirical and qualitative evaluations support its value as a robust and generalizable alternative to existing autoregressive and masked generative approaches.

6 Conclusion

In this paper, we introduced CodeDiffuSe, a novel structure-aware masked denoising diffusion model for source code completion and repair. CodeDiffuSe integrates syntactic and semantic inductive biases into the diffusion framework through AST-guided masking, semantic consistency regularization, entropy-based remasking, and adaptive denoising step control. These enhancements allow the model to generate code that is not only accurate at the token level but also structurally valid, compilable, and functionally coherent.

Extensive experiments across four diverse benchmarks—CodeXGLUE, Defects4J, QuixBugs, and CodeEdit—demonstrate that CodeDiffuSe consistently outperforms state-of-the-art autoregressive and masked baselines across a broad spectrum of metrics including Exact Match, CodeBLEU, AST accuracy, compilation rate, and test case success. Ablation studies confirm the individual and joint contributions of each architectural module, while qualitative analysis and interpretability visualizations reveal how CodeDiffuSe maintains block-level coherence and semantic alignment during generation.

To our knowledge, CodeDiffuSe is the first masked diffusion framework that integrates AST-guided masking, compiler-based semantic regularization, and adaptive denoising for code generation, offering both theoretical innovation and empirical gains over prior autoregressive and masked baselines.

By unifying structure-preserving corruption, semantically grounded decoding, and adaptive inference into a single masked diffusion framework, CodeDiffuSe advances the state of the art in robust and explainable code generation. Its modular design makes it extensible to more specialized settings such as educational code feedback, domain-specific language modeling, and integration with symbolic reasoning tools.

Future work will extend our framework to underrepresented and low-resource programming languages (e.g., Rust, Kotlin), and explore domain-specific adaptation for industrial codebases with heterogeneous structure and documentation quality.

Future work may explore tighter integration with program analyzers, hybrid symbolic-neural decoding, and reinforcement-guided diffusion sampling based on test feedback. We also envision extending CodeDiffuSe to multimodal scenarios involving code-docstring pairs, natural language interfaces, or visual programming environments. Ultimately, CodeDiffuSe represents a flexible and interpretable foundation for next-generation intelligent code assistants.
